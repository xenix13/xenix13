## 🧑‍💻 About me

I'm a 26-year-old **systems and network engineer** based in France. By day I work on infrastructure; in my spare time I'm learning to code — and I'll be honest, I'm still a beginner in that field.

What drives me is simple: building **useful tools that showcase what a home-made infrastructure can do**. Self-hosting, owning your data, and making it all run smoothly on your own hardware — that's the spirit behind everything I publish here.

## 🤖 How I use AI

AI is a big part of how I work. It helps me **turn my ideas into real, working projects** much faster than I could on my own as a beginner developer. I bring the vision, the infrastructure know-how and the testing on real hardware; AI helps me with the code.

I'm fully transparent about it, and that's exactly why **your feedback matters so much**: if you spot something that could be cleaner, safer or smarter, please tell me.

## 🚀 Flagship project: Nexis

<table>
<tr>
<td>

**[Nexis](https://github.com/xenix13/Nexis)** is my first major project: a **new alternative to existing self-hosted media servers**.

The goal is to combine **performance, accessibility and features** in a single product:

- 📚 Full media server — library scanning, metadata and transcoding built in
- 👤 Per-user spaces — watch history, visible content, personalized display
- ⏭️ Intro detection with a skip-intro banner
- 🎨 Customization and a lot of features
- 📱 Installable app and webapp (PWA) + a lightweight Android TV app
- 🏠 Fully self-hosted, designed to run in a VM, Docker container or an LXC container
